# Role

USGS removed the Church, Cemetery and School classes in 2021 and has archived the file
unchanged since. Its staleness is a feature: it predates the modern church-plant naming
wave.[^design] The adapter (`src_gnis()`) reads the 2021-08-25 snapshot's Church class; the
manifest records 231,707 rows, retrieved 2026-09-25.[^manifest]
